# CodexMeter Companion — Windows 3.12.3.1

Fixes update checks after the repository rename to **CodexMeter-Companion**.
The companion now queries GitHub's stable repository ID, so the rename no longer
causes an update-check error. Download links point to the renamed repository.

Download **CodexMeter.exe** below. Quit the running companion from its tray menu,
replace your existing executable and start it again. Keep the same file location
if a login shortcut already points there. No Python installation is needed.

This is a desktop-only release. Existing Waveshare C6 and Spotpear Ball firmware
continues to work; **no flashing is required**. Firmware downloads remain available
in the [previous release](https://github.com/roel-v/CodexMeter-Companion/releases/tag/windows-c6-2026.11.13.1).

The README now presents both displays together and includes the printed C6 case
photo. User settings, device registration and pricing history are preserved.
Automatic release checks can still be disabled; updates are never installed automatically.

Older executables may be unable to check for releases after the repository rename.
Installing this executable restores that function; Bluetooth operation is unaffected.
The historical windows-c6 tag format is retained for version comparison.
