# Windows / C6 / Ball release — 2026-11-13.1

Windows application: **3.12.3.0**. Release tag: windows-c6-2026.11.13.1.
Download the standalone Windows executable and the firmware matching your exact board from the release assets.

- Add the Spotpear ESP32-S3 1.28-inch Ball V2 firmware target and three peer pages:
  quota/tasks, Today, and seven-day token/API-cost detail.
- Support independent mixed-model display status, brightness, rotation and screen
  controls in the Windows Displays panel. Keep legacy C6 support.
- Validate optional identity/protocol/capability metadata and isolate unsupported devices.
- Coalesce queued settings per command, preserve newer desired state after late ACKs,
  and discard completion notifications older than 60 seconds on delivery/reconnect.
- Preserve the selected Ball page across waiting/completion screens; avoid waking an
  explicitly powered-off display merely because data resumes.
- Preserve pricing history, credentials, existing registration and startup behavior.

Use CodexMeter.exe without installing Python. Select the factory firmware image
for the **exact board**, verify its SHA-256 and follow the included flashing guide.
Ball firmware and C6 firmware are not interchangeable. Factory images use offset 0.
The shared screen-off/reconnect fix is included in the accompanying C6 build;
normal data delivery remains compatible with existing C6 firmware.

Validation: automated regression suite; both physical displays receiving data from
one process; 10 real BLE reconnect cycles each; targeted controls; actual Ball
framebuffer boundary/alert/rotation checks; user-confirmed touch/BOOT/readability.
See docs/spotpear-ball.md for the compatibility matrix and complete scope.

Not tested: three host sleep/resume cycles and the four-hour sustained run,
explicitly deferred by the user to production. Rotated finger gestures and more
than two simultaneous physical displays are also not certified.
No automatic installation, flashing or app restart watchdog is added.
